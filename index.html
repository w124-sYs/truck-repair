📊 Excel导出

选择要导出的表格类型,导出为 Excel 文件。

📄 表一 · 维修主表
一行 = 一次维修
维修单号 / 日期 / 车牌号 / 维修项目 / 工时费 / 合计金额 / 开单人 / 备注
🔩 表二 · 配件明细表
一行 = 一个配件
维修单号 / 配件名称 / 数量 / 单价 / 金额 / 是否借用 / 备注
说明:
· 表一用于查看每次维修的总体情况(项目、工时费、合计金额)。
· 表二用于查看配件明细,一个配件占一行,便于统计单品用量与金额。
· 两表通过「维修单号」关联,可在 Excel 中用公式自动汇总。
